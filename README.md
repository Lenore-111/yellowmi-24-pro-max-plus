# 世界小手机

用于 SillyTavern 的手机界面扩展，可在角色聊天旁使用桌面、锁屏、相册、社交互动、钱包、小游戏与自定义皮肤。当前版本：0.3.0-alpha.17。

## 安装与更新

1. 打开酒馆的「扩展」→「安装扩展」。
2. 填入仓库地址：https://github.com/Lenore-111/yellowmi-24-pro-max-plus
3. 安装后刷新页面，点击屏幕边缘的小手机按钮。

需要 SillyTavern 1.12.0 或以上版本，无需另外构建或启动服务。更新可使用酒馆的扩展更新入口或手机里的更新提示。请仅启用一份小手机扩展，避免重复加载。

## 桌面、相册和皮肤

- 浮动入口可拖动，松手后吸附到左右边缘，空闲约两秒后向屏幕外半隐藏；再次拖动、贴边后仍会自动收起。
- 桌面支持应用排列，桌面与锁屏可分别设置壁纸。
- 相册支持批量导入本机图片、查看、收藏、删除和设置壁纸。
- 「应用商店」→「主题」提供蓝色大肥鱼、粉色两套内置皮肤，也可制作自定义皮肤。
- 自定义皮肤可分别上传桌面壁纸、锁屏壁纸和应用图标；图标支持批量选择、按应用顺序分配，以及一张图片用于多个应用。
- 自定义皮肤支持整套导入、导出分享和备份。连接酒馆时保存到当前账号，重新进入同一账号可恢复。

## 独立手机生活

打开角色聊天后使用小手机，新存档默认进入独立游戏模式。可让角色发动态，进行点赞、评论、私聊与送礼，并查看共同经历。角色回应使用酒馆当前连接的模型。

钱包里的街角咖啡店可以打工获得独立游戏余额。玲七快送提供餐饮与礼物互动，杯装可乐售价十八元，购买后显示小猫台词：“贵是贵了点，但喝着舒服，不烧心”。商家演示订单的配送费另行计算。

手机内的经历单独保存。需要接入正文时，使用「带入正文」预览自己的行动，再将草稿放入正文输入框并自行发送。

## 狼人杀与本机应用

狼人杀支持六至十二人，你与其余人工智能玩家同桌。点击「让鸦发牌」，查看并确认自己的身份后进入夜晚；乌鸦主持人提供阶段提示，对局自动保存在当前浏览器。未连接模型时使用本地策略。

手机还提供音乐播放、计算器、本机小游戏和相关应用入口。应用商店中标注尚未开放的应用暂不可安装。

## 世界背面联动

在设置中切换至世界背面模式，并启用提供第二版手机桥接口的世界背面扩展。连接后，小手机显示接口开放的联系人、消息、动态和公开世界信息；可用操作以世界背面提供的能力为准。

独立游戏与世界背面联动使用各自的记录和钱包。未连接世界背面时，相应世界数据和操作不可用。
