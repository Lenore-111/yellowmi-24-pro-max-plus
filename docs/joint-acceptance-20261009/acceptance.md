## 实际复现与修复

| 点赞异步完成时清掉新打开的评论框 | 微信重绘保留当前弹窗与焦点 | `moment-like-race/` |

### 关键边界

世界背面的固定手机桥没有蜂窝电话／短信写能力和可用手机号。世界模式电话显示“无法接通”，短信显示没有可用联系人；没有假接通、独立模型回退或绕过 phoneAction 写世界数据。独立通话实际接通，切模式结束通话。

短信生成中切聊天后，原请求取消，服务端迟到计算没有写入新聊天；回原聊天仍可找到 pending 短信。真实切分支 B 得到 B 的独立社交数据，回 A 恢复 A 的消息。切角色后旧界面和旧数据清理。

## 复跑入口

脚本为 `harness/social.mjs` 与 `harness/isolation.mjs`。路径按 `joint-acceptance` 目录组织，真实 ST、两个插件及实验酒馆均需按上表安装；使用隔离测试数据目录，先执行 social，再执行 isolation。Playwright 启动真实 Chromium，不使用页面 DOM 模拟器。

social 准备测试人物和第二聊天；isolation 复用它们，准备两条真实 swipe 分支，启动本地模型服务后执行页面操作。详细选择器、正常 API fixture 准备、模型请求时间、保存请求快照均保留。
