# 数据保存与备份

不同功能使用不同存储范围：

| 数据 | 保存位置 | 更换浏览器后 |
| --- | --- | --- |
| 自定义皮肤素材、列表及应用状态 | 连接酒馆时保存在当前账号的用户文件；浏览器尽可能保留副本 | 登录同一服务器的同一账号后恢复 |
| 独立手机生活及本机应用交互记录 | 当前酒馆聊天元数据 | 随该聊天数据保留 |
| 相册导入的本机图片与独立相册壁纸 | 当前浏览器的 IndexedDB | 需要重新导入 |
| 狼人杀对局及发牌状态 | 当前浏览器本地存储 | 不跨浏览器同步 |
| 桌面排列、浮动入口位置等设备偏好 | 当前浏览器本地存储 | 按新浏览器默认值开始 |

自定义皮肤的账号文件使用 `world-phone-skins-v1.json` 作为目录，素材包使用 `world-phone-skin-*.json`。普通相册图片不上传到酒馆，也不写入聊天或世界数据。

未连接酒馆时，自定义皮肤只保存在浏览器。清理站点数据、换访问域名或端口，会影响浏览器本地数据。建议用「导出分享」备份自定义皮肤；服务器侧的账号文件也应随酒馆数据一起备份。

删除或重置操作以页面上的具体操作范围为准。
