# 独立手机游戏

打开角色聊天，再打开小手机。新存档默认进入“独立游戏 · 仅在手机里”。设置可以切换回“世界背面 · 原有联动模式”。两种模式各用自己的记录和钱包。

## 玩一轮

1. 微博或小红书点“看看新动态”，让角色按人设发帖；微信也能看朋友圈。
2. 点赞、评论，或点“私聊”继续聊同一位角色。评论、消息和礼物会进入共同经历。
3. 钱包打开“街角咖啡店”，点击“开始营业”，按配方点选原料，再点击“出杯”。选中的原料会显示勾号，再点一次可以取消。做完三杯自动入账：每班底薪 ¥10，每杯做对另加 ¥20；未选原料时不会消耗订单。
4. 点“挑礼物”，或到快送请角色吃东西。选择收礼人、写附言，购买后收到角色回应。关系页可以查看熟悉度、已发现偏好与共同经历。重复赠送同一种礼物的数值收益会下降。

角色生成使用酒馆当前模型连接，需要你已连接可用模型。失败会留下可重试的互动；送礼已扣的钱不会在重试时再次扣除。手机生成期间换聊天或换模式，迟到结果会被丢弃，原存档中的互动可以重试。单次等待超过一分钟会停止等待，也可点击“停止等待”；原消息和礼物保留，重试不会再次扣钱。正文正在生成时暂不启动手机模型请求。生成过程中离开应用再回来，已保存的回应会自动显示。

## 电话与短信

电话提供通讯录、收藏、最近通话与拨号盘。可选择联系人呼叫，也可手动输入通讯录中的号码；通话中点“说话”继续对话，点“挂断”结束。通话记录保留接听、拒接、取消、未接通与时长；点击记录可再次拨号。返回桌面后可重新打开电话继续当前通话。

角色资料有号码时优先采用资料；没有号码的角色分配稳定的游戏内号码，并在通讯录中标注。未知号码会显示未接通，不会自动生成陌生人物。

短信提供新建短信、收件人选择、独立会话与草稿保存。可以从电话通讯录直接进入短信，也可以在短信会话中呼叫对方。回复生成失败后可重试，同一条短信不会重复发送。

电话目前使用文字呈现通话，角色台词与短信回复使用酒馆当前连接的模型。短信、通话和微信分别显示各自的记录，与同一位角色的共同记忆持续保留。它们均属于手机内的独立游戏通讯。

## 和正文的衔接

角色卡、用户人设及开局时最近六条正文只作为这份手机生活的起点。之后以手机内经历继续发展；正文后续消息不会不断改变手机生活。切换角色、用户身份或聊天会使用分别保存的手机存档。同一聊天继续正文、编辑正文或切换回复候选，不会重置这份独立手机生活。旧版按正文楼层拆开的手机存档，会自动恢复同一角色、身份与聊天中进度最完整的一份；原记录全部保留，不叠加余额或重复结算礼物。

浏览、聊天、发帖、工资、礼物、好感与记忆都保存为小手机自己的聊天元数据 `world_phone_game_v1`。它们不会自动写入正文消息、`world_backstage_v1` 或正文扩展提示词，也不会调用世界背面的社交写命令。

想把一次经历接入正文时，点该互动的“带入正文…”。预览只包含你自己的行动；“放入正文输入框”只填草稿，由你检查并发送，正文里的角色重新决定回应。不会导入手机回复或熟悉度数值。

人物角色卡和世界背面提供的已认识联系人可以进入角色列表；世界观、多人剧情和模拟器卡的标题不会作为人物出现。消息、赠礼和评论中的称谓优先采用人物资料中的代词；无法确定时使用角色名。更新后旧存档自动修正列表和显示称谓，余额、真实角色的聊天与送礼记录继续保留。

没有可用人物时会显示角色提示。钱包的咖啡店和礼物使用独立游戏余额；原有赌场及其他本机小游戏仍使用各自已有存档。

## 回归验证

安装 Node.js 22 或更新版本后，在仓库根目录运行：

```sh
node --test tests/phone-game-regression.test.mjs
```

测试直接执行模块代码，并模拟酒馆上下文、页面与模型请求，覆盖存档迁移、生成超时与取消、页面重开刷新、正文生成阻挡及聊天切换。真实酒馆页面与模型连接仍需在宿主中验证。
