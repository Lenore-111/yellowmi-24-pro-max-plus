# 独立手机游戏

打开角色聊天，再打开小手机。新存档默认进入“独立游戏 · 仅在手机里”。设置可以切换回“世界背面 · 原有联动模式”。两种模式各用自己的记录和钱包。

## 玩一轮

1. 微博或小红书点“看看新动态”，让角色按人设发帖；微信也能看朋友圈。
2. 点赞、评论，或点“私聊”继续聊同一位角色。评论、消息和礼物会进入共同经历。
3. 钱包打开“街角咖啡店”，看配方、选原料、做三杯饮品。每班底薪 ¥10，每杯做对另加 ¥20，完成自动入账。
4. 点“挑礼物”，或到快送请角色吃东西。选择收礼人、写附言，购买后收到角色回应。关系页可以查看熟悉度、已发现偏好与共同经历。重复赠送同一种礼物的数值收益会下降。

角色生成使用酒馆当前模型连接，需要你已连接可用模型。失败会留下可重试的互动；送礼已扣的钱不会在重试时再次扣除。手机生成期间换聊天或换模式，迟到结果会被丢弃，原存档中的互动可以重试。

## 和正文的衔接

角色卡、用户人设及开局时最近六条正文只作为这份手机生活的起点。之后以手机内经历继续发展；正文后续消息不会不断改变手机生活。切换角色、用户身份、剧情分支或聊天会使用分别保存的手机存档。

浏览、聊天、发帖、工资、礼物、好感与记忆都保存为小手机自己的聊天元数据 `world_phone_game_v1`。它们不会自动写入正文消息、`world_backstage_v1` 或正文扩展提示词，也不会调用世界背面的社交写命令。

想把一次经历接入正文时，点该互动的“带入正文…”。预览只包含你自己的行动；“放入正文输入框”只填草稿，由你检查并发送，正文里的角色重新决定回应。不会导入手机回复或熟悉度数值。

没有选择角色卡时会显示选择角色提示。钱包的咖啡店和礼物使用独立游戏余额；原有赌场及其他本机小游戏仍使用各自已有存档。
