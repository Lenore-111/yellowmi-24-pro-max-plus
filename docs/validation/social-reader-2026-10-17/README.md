# 社交平台阅读体验与内容连续性

## 行为

- 自动/手动刷新共用「正在更新、已同步、更新失败」状态，失败显示原因和重试按钮；刷新入口改名「刷新动态」。状态按聊天、角色、模式与世界分支隔离。
- 后续新动态和内容更新先显示数量提示，点击后才替换正在读的信息流。后台到达内容不会重建搜索输入框，保留焦点、草稿、详情展开与阅读位置。首次打开并且尚未阅读/输入时可以直接完成首轮同步。
- 实际撤回或失去可见性的内容立即移除；好友动态缓存短暂失效但其源动态仍可见时继续保留阅读副本，防止刷新期间闪退帖子。切聊天、分支、模式或断线不保留旧世界内容。
- 设置统计收进「连接详情」，刷新保留展开与滚动位置；独立开关改名「自动同步世界动态」，使用可访问的滑动开关。
- 微博提供推荐/好友信息流、热搜与讨论串；小红书提供全部/美食/出行/日常分类、两列生活笔记、文字封面摘要与图数。文字笔记不伪造图片，封面配色按帖子ID固定。
- 世界背面持续新闻保留原ID与首次发布时间；论坛续帖保留身份、追加并去重讨论（缓存最多八条），新主题保留旧主题。生成提示要求续帖引用原ID，缺省主题ID不再依赖返回顺序。手机用首次世界发布时间显示时间，更新另标「有更新」，收藏/点赞继续引用同一ID。
