# 动态配图密钥设置验收

基于主分支 `29d765bb4a4924e16a7d2d25f233d957519cf70c`，只修复生图设置控件。

## 复现与修复

实际酒馆页面中，原勾选框点击能切换 `checked`，但共用文本输入框的 `padding: 10px`，使 22 像素的方框里只剩很小的勾选标记。旧酒馆的勾选框选择器还包含多个 ID 排除条件，普通样式覆盖无法恢复原生外观。

文本输入框样式现在排除勾选框；「在此设备记住密钥」使用 22 像素的原生勾选框、44 像素高的整行点击范围，局部覆盖宿主样式并保留键盘焦点标记。密钥栏继续支持手动粘贴，关闭自动大写、自动纠正和拼写检查。
