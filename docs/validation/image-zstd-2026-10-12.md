# 站点压缩响应兼容与生图错误定位（2026-10-12）

结论有两部分：模型读取是已复现的兼容缺口，本次已修复；真实生成仍未通过，生成接口的独立请求也返回 Cloudflare 502，需要站点侧继续排查。

## 模型列表的实际原因

对同一 `https://gensoukyou.xyz/v1/models` 和会话凭据做非生成请求对照：

- 接受包含 Zstandard 的编码时：200、响应编码 `zstd`，982 字节，帧前缀 `28b52ffd`；直接当 JSON 解析失败，正确解压后返回 82 个模型。
- 只接受酒馆请求库支持的编码时：200、Brotli 响应自动解压为 10184 字节，JSON 可读取，仍为 82 个模型。
- 不使用压缩时：200、10184 字节，仍为 82 个模型。

此前「返回网页」的判断不准确，模型响应实际为未解开的压缩数据。酒馆的通用代理会转发浏览器压缩协商头，请求库未解码此格式，转发到客户端时又没有保留响应编码。小手机因此收到了压缩字节而不是已解压的 JSON。现按帧标识兼容这一响应，普通 JSON、图片和 ZIP 不重复解码；适用于模型列表、图片 JSON 及已复现的结构化上游错误，无需用户修改酒馆文件。

解码器使用 `fzstd` 0.1.1，保留 MIT 许可。解码前检查帧、声明大小、窗口和块数；解码输出保持既有大小限制，处理过程中可取消，不回显服务响应或凭据。

## 验证

69/69 自动测试通过，覆盖压缩模型列表和图片 JSON、原有普通响应、连续帧、截断、声明及窗口超限、实际解码输出上限、取消。相关语法检查及差异检查通过。

## 生图的独立问题

绕过小手机和酒馆通用代理，以相同型号、提示词、单张参数直接请求 `/v1/images/generations`，只协商请求库支持的压缩格式，仍返回 502。第一次独立请求未完整提取错误字段，为采集详细原因补发了一次同参数请求；两次均失败、均没有返回图片，不计为真实生成通过，也没有自动重试。

详细响应属于 Cloudflare 的结构化网关错误，说明源站返回了无效或不完整响应；可能原因示例不能当作已确定结论。客户端证据不足以判断具体是站点过载、配置或生成上游故障，需要站点服务端日志。不能把 502 和模型列表的解压问题合并为同一个原因，也不能据此断定密钥没有权限。
