# 用户自配生图接口验收（2026-10-11）

基于 Yellow Mi `1de3846dca9947442626717c79763dce69d74fcc` 的独立功能分支。没有合入动态兼容修复 PR #5 或初始余额 PR #6，未改自动更新、主分支或发行版本。

## 范围和环境

第一版为独立模式的微博、小红书、朋友圈增加手动配图。用户填写站点、密钥并选择或手填模型；无内置供应商、模型、密钥或额度。世界模式不增加配图写操作。

实际启动官方 SillyTavern 1.18.0（`51ad27fb86d39a3daca3adaa970375c9670c12df`）和 1.12.0（`53496d70f1cfca7891d75058e8be39999ea67657`），将本分支文件安装到账号扩展目录，由 Chromium 153 / Playwright 操作真实页面。图像接口是本地 OpenAI 兼容服务夹具：固定返回一张已有 PNG，也支持图片 URL、带签名参数的 URL、受控 HTTP 500 和延迟响应。不调用付费生图服务，不据此声称任意生图站点兼容。

1.18.0 在页面点击刷新得到模型夹具生成的动态；1.12.0 因既有 `getContext().generateRaw` 兼容缺陷（独立追踪在 PR #5），只预置动态测试数据，随后实际点击设置、模型选择和配图。1.12.0 的本项结果不计为“动态文字刷新已通过”。
