# 本机图片导入

在小手机打开相册，点击“导入图片”，选择设备照片，可一次选择多张。导入后的图片显示在“全部”和“本机”，点开可查看大图、收藏、设为主屏幕、锁屏或同时设置，亦可删除。相册提供恢复默认壁纸。

图片使用浏览器 IndexedDB 保存原始文件，不上传到世界背面，不写入聊天元数据；同一浏览器站点的聊天共用本机图片与壁纸。重新加载仍可读取，清除站点数据会移除图片；不随聊天导出或跨设备同步。删除壁纸来源图片时，对应壁纸恢复默认。

支持浏览器能够解码的普通照片、截图和动图，每张不超过 20 兆字节。矢量图和高效图片格式需要先转换。取消选择不改变数据；多张中部分失败时，成功图片保留，并显示失败文件与原因。存储受限或空间不足时显示错误。
