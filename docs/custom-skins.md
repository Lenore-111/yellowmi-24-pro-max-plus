# 自定义小手机皮肤

入口：应用商店 → 主题 → 自定义。

## 自己制作

1. 点“制作皮肤”，填写名称并选择桌面壁纸。锁屏默认使用同一张图片，也可以取消勾选后另选一张。
2. 点“上传图标”或“批量选择图标”，选一张或多张图片。每张图片旁的“选择应用”可展开勾选多个应用，同一图片可以同时用于微信、相册、音乐等。一张图片时可点“一张图片用于全部应用”，一次选择全部17个应用；每张图也有“全选应用”“清空选择”和“跳过本张”。多张图片可按下方应用顺序填充空项，已有分配会保留，没有空项时明确提示。不需要改文件名，应用名文件会自动预选。核对后点“添加所选图标”，再点“保存并应用”。若不同图片选了同一应用，会提示冲突供你调整，不会偷偷覆盖。损坏图片会单独说明原因，其他有效图片仍可使用。
3. 推荐透明 PNG 图标；未上传图标的应用保留原图标。壁纸和图标支持 PNG、JPEG、WebP，单张不超过 20MB，整套不超过 40MB。
4. 勾选要应用的部分，点“保存并应用”。以后可以在保存的皮肤里编辑、应用或删除。

## 分享和导入

在保存的皮肤上点“导出分享”，得到一个 `.phone-theme.json` 文件，里面包含名称、壁纸和各个应用的图标，不需要另外发送图片文件夹。

收到分享文件后点“导入整套皮肤”，选择文件，预览后点“保存并应用”。导入会新增一套，不覆盖同名皮肤。损坏或不支持的包不会改变当前皮肤。

连接酒馆时，皮肤素材与当前应用状态保存到酒馆账号的用户文件目录，并在浏览器中保留副本。重新从终端启动酒馆、重新进入页面或浏览器副本丢失后，会从同一个酒馆账号恢复壁纸、图标和皮肤列表。保存失败会显示错误，不会提示成功。素材不会进入聊天记录或世界数据。

没有酒馆连接的独立预览仍使用浏览器本地存储。清除浏览器数据前请导出需要保留的皮肤。导出文件仍可用于备份或分享，最多保存 20 套。
