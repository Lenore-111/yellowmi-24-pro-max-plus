# 动态配图

小手机只提供调用入口，用户自行选择生图站点、密钥和模型，费用与额度由所选站点决定。默认手动生成，不会在刷新动态时自动调用生图服务。

## 设置与使用

1. 打开手机「设置」→「连接自己的生图站点」。
2. 按站点说明选择「OpenAI 兼容」或「NovelAI 生图」接口类型，再填写站点提供的 API 地址。不要填写登录或注册页面。
3. 填写自己的密钥。无需密钥的本地服务可留空。
4. 通用兼容接口可点击「读取模型列表」，从列表选择站点支持生图的模型；站点不提供列表时直接填写。NovelAI 类型不读取通用模型列表，请直接填写站点提供的生图模型名称。
5. 可填写尺寸、默认画风。通用接口尺寸留空时由站点决定；NovelAI 留空默认 1024x1024，宽高须为 64 的倍数，总像素不超过 1024x1024。
6. 保存设置后，打开独立模式的微博、小红书或朋友圈，点击动态下的「配图」，检查或修改提示词，再点击「生成一张」。

已有图片可以重绘；生成失败保留原图。成功图片保存到酒馆账号的素材目录，动态存档只记录文件路径和提示词，刷新后可以恢复。点击「保存到相册」可再存一份到本机相册，用于查看或设置壁纸。

## 接口要求

### OpenAI 兼容

基础地址示例：`https://你的站点/v1`。也可填完整的 `images/generations` 地址；插件会提取基础地址。旧设置保持此接口类型。

- 生图使用 `POST {基础地址}/images/generations`，JSON 参数包含用户填写的 `model`、`prompt`、`n: 1`，以及可选 `size`。
- 读取模型使用 `GET {基础地址}/models`，支持 `data: [{id: "模型名称"}]`。模型列表可能包含文字模型，需自行选用生图模型。
- 密钥以 `Authorization: Bearer ...` 发送。图片响应支持 `data[0].b64_json` 或 `data[0].url`。
- 支持 PNG、JPEG、WebP，单张最多 20 MB。返回 URL 时先下载并另存到酒馆；下载图片不附带生图密钥。
- 生图最长等待三分钟，可取消。插件不强制 `response_format`，不绑定任何供应商或预设模型。

### NovelAI 生图

填写站点提供的 NovelAI 基础地址，例如 `https://你的站点`；也支持完整的 `/ai/generate-image` 地址。插件不会为此类型自动添加 `/v1`，也不会请求 `/models`。自定义站点的路径以其说明为准。

- 生图使用 `POST {基础地址}/ai/generate-image`，发送用户填写的模型、`input`、`action: generate` 和专用参数；V4/V4.5 模型附带相应的提示词结构。
- 每次一张、28 步，默认 1024x1024。不使用图生图、参考图、氛围图或队列，不自动重试或循环生成。公益站仍需具备该站要求的账号权限，遵守其尺寸与使用限制。
- 读取 ZIP 压缩包中的首张 PNG、JPEG 或 WebP，也支持原生 JSON 的 `images[0].image` base64 返回。解码不依赖浏览器的 `DecompressionStream`，图片上限仍为 20 MB；解码时可以取消。
- 模型按站点说明手填，例如支持该模型的站点可填写 `nai-diffusion-4-5-full`。不提供或假装从站点读取模型列表。
- 建议使用英文标签提示词。新增动态的配图描述会随既有文字生成一起输出英文标签，正文保持中文；旧动态的提示词可在生成前手动编辑，不额外调用文字模型翻译。
- 密钥仍使用用户在小手机里单独填写的站点密钥。浏览器直连和酒馆代理均可使用，图片保存、相册及聊天隔离沿用现有流程。

本版仍不支持其他站点专有协议、轮询任务接口、图生图或参考图上传。不能仅凭站点“支持生图”判断其接口兼容。

浏览器直连需要站点允许跨域（CORS）；页面使用 HTTPS 时，浏览器还可能阻止 HTTP 站点。可改用 HTTPS 接口，或选择「酒馆代理」。酒馆代理复用宿主的 `/proxy/`，需酒馆管理员在 `config.yaml` 开启 `enableCorsProxy: true` 后重启酒馆。插件不修改酒馆服务器配置，也不另起服务。

站点返回的 404 会提示检查接口类型和地址；只有响应明确说明酒馆代理未开启时才提示开启代理，不再将站点路径错误误报成代理问题。

## 密钥与存档

接口地址、模型和画风存入酒馆账号的扩展设置。密钥默认只在本次页面会话内保留，刷新后需重新填写。勾选「在此设备记住密钥」后保存在当前浏览器的本地存储，不进行加密或跨设备同步；适合自己的设备。可随时点击「清除已保存密钥」。更换接口地址不会沿用旧站点密钥。

密钥不写入聊天、世界数据、提示词、素材文件或插件日志，也不借用正文模型密钥。配图会将提示词发送到用户所选站点，请在生成前检查内容。

切换聊天、角色、分支或手机模式会取消旧生成；迟到的图片不会写入新聊天。世界模式暂不提供该配图入口，不通过独立存档改写世界动态。新素材上传期间若切换存档，插件会清理未挂载的素材。成功重绘后保留旧素材文件，避免破坏引用旧图的聊天分支。

备份时，动态元数据和酒馆账号的 `files` 素材目录应一起保留；本机相册是单独的浏览器存储。
