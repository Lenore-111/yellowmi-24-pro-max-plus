# 配套安装与更新

小手机 0.3.0-alpha.28 的世界背面联动配套版本为世界背面 2.5.9。只使用独立手机生活时，无需安装世界背面。

## 安装

1. 在酒馆的扩展安装入口安装小手机：https://github.com/Lenore-111/yellowmi-24-pro-max-plus
2. 需要联动时，再安装世界背面：https://github.com/h675786161-prog/world-backstage
3. 刷新页面，选择聊天并初始化世界背面。
4. 打开小手机的设置，选择世界背面模式，确认连接状态正常。

请只启用一份小手机和一份世界背面，避免重复挂载。真实联合验收使用酒馆 1.18.0；其他宿主版本以实际兼容情况为准。

## 更新已有安装

更新前备份聊天；自定义皮肤可在手机中导出。手动更新两份扩展后刷新页面，再检查世界连接和原聊天中的手机记录。两边保持关闭自动更新，避免只更新其中一份。

本版沿用已有聊天元数据和本机存储键，不要求清空聊天、删除皮肤或重新导入存档。同名人物按各自身份区分；人物改名不会将消息转给另一个同名人物。

如果保存失败，保留原输入或待回应短信，恢复连接后重试。不要重复新建同一条短信；短信中的“重试回复”使用原记录，不再次发送原短信或扣除礼物余额。

## 功能边界

世界模式支持好友申请、私聊、群聊、已读、朋友圈点赞和评论。操作等待世界背面保存确认后才完成；切聊天、角色、玩家身份、分支或模式后，旧页面和旧确认结果失效。

世界模式电话和短信暂不提供通话、收发能力。独立模式的角色电话和短信使用酒馆模型，在独立记录中保存，不修改世界状态。

## 恢复

遇到问题时先停用手机扩展，保留聊天与手机存档，并记录两边版本和报错。可将两份扩展一起恢复为此前配套版本后刷新；如已使用新版本写入记录，先保留备份，再决定是否恢复旧聊天。不要用清空数据作为更新步骤。
