# 狼人杀

## 开局与发牌

打开狼人杀，填写名字，选择六至十二人的人数。你占一个座位，其余由人工智能玩家参与。

点击「让鸦发牌」，乌鸦主持人会向各座位发出背面身份牌。自己的身份牌放在座位列表前，直接点牌即可查看身份，记住后再点「身份记住了，进入夜晚」。确认前，对局不会推进。

## 对局流程

夜晚按身份使用行动：狼人选择目标，预言家查验玩家，女巫决定是否使用药剂。猎人满足发动条件时可决定开枪或放弃。

白天会先停下来等你。输入判断后点「发言」，或点「跳过我的发言，让其他玩家继续」。其他玩家发言期间仍可以补充；全部发言结束后点「进入投票」，选择目标并确认。

「对局信息」显示公开的夜晚结算及你的个人行动。女巫可查看解药、毒药余量，以及本夜救人、毒人或不用药的结果；预言家可回看本人查验；狼人可查看自己提交的目标。「我的行动记录」随对局保存，其他身份不会看到你的私有记录。旧存档可恢复当前夜晚的用药和查验信息；旧版没有保存的往夜目标无法恢复。

乌鸦会随当前阶段给出主持提示。界面按你的身份展示允许查看的信息，游戏结束后公开身份与结果。

「模型对局」使用酒馆可用模型，公开发言与夜间动作使用较短的回复长度。等待面板显示白天发言进度，夜晚不会公开其他玩家的行动者身份。

想立即推进时，可选择「本地快速」，或在等待中点「本地快速继续」。本地模式使用即时策略，推理与发言较简单，不依赖模型速度。单条模型请求等待超过三十秒时，当前自动流程使用本地策略继续；迟到的模型结果不会重复加入对局。下一次操作会再次尝试模型，仍未结束的旧请求不会触发新的并发调用。

## 继续与结束

对局自动保存在当前浏览器，发牌与翻牌状态也会保留。返回手机后重新打开狼人杀，可继续当前对局。

「放弃这局」需要再次点击确认。结束后可以回到开局页重新发牌。清除浏览器站点数据会移除本机对局，存档不随酒馆聊天导出或跨浏览器同步。
