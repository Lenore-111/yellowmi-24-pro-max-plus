# 狼人杀

## 开局与发牌

打开狼人杀，填写名字，选择六至十二人的人数。你占一个座位，其余由人工智能玩家参与。

点击「让鸦发牌」，乌鸦主持人会向各座位发出背面身份牌。点「查看我的身份」，记住后再点「身份记住了，进入夜晚」。确认前，对局不会推进。

## 对局流程

夜晚按身份使用行动：狼人选择目标，预言家查验玩家，女巫决定是否使用药剂。白天阅读其他玩家的发言，也可以参与讨论；讨论结束后选择目标并确认投票。猎人满足发动条件时可决定开枪或放弃。

乌鸦会随当前阶段给出主持提示。界面按你的身份展示允许查看的信息，游戏结束后公开身份与结果。

人工智能玩家优先使用酒馆可用模型，没有可用模型时使用本地策略。

## 继续与结束

对局自动保存在当前浏览器，发牌与翻牌状态也会保留。返回手机后重新打开狼人杀，可继续当前对局。

「放弃这局」需要再次点击确认。结束后可以回到开局页重新发牌。清除浏览器站点数据会移除本机对局，存档不随酒馆聊天导出或跨浏览器同步。
