# 狼人杀

## 开局与发牌

打开狼人杀，填写名字，选择六至十二人的人数。你占一个座位，其余由人工智能玩家参与。

点击「让鸦发牌」，乌鸦主持人会向各座位发出背面身份牌。自己的身份牌放在座位列表前，直接点牌即可查看身份，记住后再点「身份记住了，进入夜晚」。确认前，对局不会推进。

## 对局流程

夜晚按身份使用行动：狼人选择目标，预言家查验玩家，女巫决定是否使用药剂。猎人满足发动条件时可决定开枪或放弃。

白天会先停下来等你。输入判断后点「发言」，或点「跳过我的发言，让其他玩家继续」。其他玩家发言期间仍可以补充；全部发言结束后点「进入投票」，选择目标并确认，也可以选择「弃票 · 不投任何人」再确认弃票。确认前可以改选，提交后本轮不能重复投票。弃票算作完成投票，不增加任何人的得票；全员弃票或最高票平票时，当日不放逐任何人，正常进入下一夜。人工智能玩家也可以弃票。

发言区上方的「夜晚信息」直接显示第几夜、死亡玩家的座位和名字，平安夜会显示无人死亡。女巫能看到自己救了谁、毒杀了谁或没有用药，以及剩余药剂；狼人能看到自己选择的刀口、狼队最终刀口和该目标是否被狼刀杀死；预言家能看到查验对象和阵营结果。

「夜晚与行动记录」随对局保存，可回看历夜结算与本人的操作。进入下一夜后，上一次结算及个人结果仍然显示，其他身份不会看到你的私有记录。旧存档可恢复已有死亡记录、当前夜晚的用药与狼刀目标，以及本人查验；旧版没有保存的往夜技能目标无法恢复。更新扩展后需要刷新整个酒馆页面，才会载入新的对局界面。

简约像素乌鸦会随当前阶段给出主持提示。界面按你的身份展示允许查看的信息，游戏结束后公开身份与结果。

「模型对局」使用酒馆可用模型，公开发言与夜间动作使用较短的回复长度。等待面板显示白天发言进度，夜晚不会公开其他玩家的行动者身份。

想立即推进时，可选择「本地快速」，或在等待中点「本地快速继续」。本地模式使用即时策略，推理与发言较简单，不依赖模型速度。单条模型请求等待超过三十秒时，当前自动流程使用本地策略继续；迟到的模型结果不会重复加入对局。下一次操作会再次尝试模型，仍未结束的旧请求不会触发新的并发调用。

## 继续与结束

对局自动保存在当前浏览器，发牌与翻牌状态也会保留。返回手机后重新打开狼人杀，可继续当前对局。

「放弃这局」需要再次点击确认。结束后可以回到开局页重新发牌。清除浏览器站点数据会移除本机对局，存档不随酒馆聊天导出或跨浏览器同步。

发言记录会标注座位和轮次；阅读旧发言时，新发言和界面状态更新会保留当前滚动位置，已滚到列表底部则继续跟随新发言。每个模型玩家每轮都会收到固定身份、本人历次查验与实际公开原话；夜间动作未更新的记忆摘要继续保留。本地快速模式下，预言家按真实查验结果发言，模型回复不可用时也按这些记录继续。
