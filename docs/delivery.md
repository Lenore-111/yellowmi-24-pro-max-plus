# Echo快送

Echo快送提供独立手机生活中的餐饮与礼物互动，以及本机商家演示菜单。两种模式按所在界面分别保存记录。

## 独立手机生活

选择收礼人和商品，可填写附言。购买使用独立游戏钱包余额，角色回应使用当前酒馆模型连接。生成失败时可以重试，已扣金额不会重复扣除。

杯装可乐售价十八元，购买后小猫会说：“贵是贵了点，但喝着舒服，不烧心”。小猫提示与角色回应分别显示。

## 商家菜单与订单

1. 打开Echo快送，按分类、搜索或商家列表选择店铺。
2. 在菜单中增减商品，购物车会显示商品金额、配送费、起送价和合计。
3. 更换商家时，先确认是否清空当前购物车。
4. 结算时填写剧情中的收餐地点，可添加备注。
5. 在「我的订单」查看订单记录与详情。

商家菜单为虚构演示数据。本机演示订单不扣钱包余额，不调用现实外卖平台或支付服务；订单保存后不模拟商家接单与骑手配送。

杯装可乐在商家菜单中同样售价十八元，商家配送费另计，结算页会显示最终金额。

## 保存范围

购物车及最多三十条演示订单按酒馆聊天分别保存。切换聊天后，再次打开快送会读取对应聊天的数据。没有酒馆聊天上下文时使用独立的浏览器本地记录。

商家订单目前不写入世界背面。世界背面联动中的正式下单和配送需要相应接口支持。
