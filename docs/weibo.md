# 微博

微博可以浏览人物动态、路人趣闻和街坊讨论。入口仍在手机桌面。

## 独立模式

点击“刷新微博”，使用酒馆当前连接的模型生成一屏消息。生成时参考当前角色资料、最近可见正文、当前绑定的世界书、手机已有帖子和经历。正文推进后，下一次刷新会读取最新内容。

“推荐”混合展示角色帖子、路人吐槽、生活趣闻和人物相关话题；“关注”只展示手机已有角色的帖子；“热议”按话题热度排列。搜索支持作者、帖子正文和讨论回复。

角色帖子可以私信作者或评论。路人帖子显示自然网名和讨论回复，可点赞、配图及查看讨论，不会自动成为联系人。已选择世界观或场景卡时，即使没有可私信的人物，也可以生成路人帖子。

世界书读取包括角色内嵌、角色绑定、当前聊天、当前人设、全局选中及角色附加书。禁用、显式私密、标注隐藏或剧透，以及不适用于当前人物的条目跳过。未绑定的书不会被扫描；读取失败时使用已取得资料。大型世界书会按相关性和随机轮换摘取部分内容。

路人讨论只应使用公开可知的信息；正文里的私人对话、人物内心和秘密不能默认变成街坊新闻。涉及人物的猜测显示为讨论或传闻。消息仍属于手机里的内容，不自动写回正文或世界背面的事件、认知和记忆。

生成期间切换聊天、人物、身份、模式或世界书，或者修改正文和回复候选，旧结果不会保存。生成失败保留已有帖子，重新刷新即可重试。角色动态和路人帖随手机存档保存，整页刷新后恢复。

## 世界模式

连接世界背面后，保留原有微博和小红书界面。微博将公开新闻、论坛讨论及关联回复映射为帖子，发现页按事件聚合热搜，个人页保留点赞和收藏。小红书筛选生活、探店、旅行等公开素材，保留笔记、多图详情、讨论、点赞与收藏。

两处页面均可点击“刷新舆情”，共用世界背面的公开素材；刷新不会清除筛选、收藏或点赞。

“刷新舆情”交给世界背面已有的舆情刷新入口处理，再读取手机可见的结果。没有新的公开变化时，宿主会复用已有舆情。若配套版本没有该刷新入口，只重新读取现有消息。微博不会读取世界背面的原始事件或私密人物状态来拼接新闻，也不会在世界模式调用独立手机生成兜底。

没有安装世界背面时，可以在手机设置中使用独立模式。
